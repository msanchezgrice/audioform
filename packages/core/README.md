# @talkform/core

Schemas, bundled interview templates, validation, and local session helpers for Talkform.

```bash
npm install @talkform/core
```

```ts
import { audioformConfigSchema, listAudioformTemplates } from "@talkform/core";
```

The package does not create hosted sessions or store interview results. Documentation: https://talkform.ai/docs/getting-started
