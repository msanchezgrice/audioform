# @talkform/react

Embeddable React widget for guided Talkform voice and text interviews.

```bash
npm install @talkform/react @talkform/core
```

```tsx
import { AudioformWidget } from "@talkform/react";
import "@talkform/react/styles.css";
```

See https://talkform.ai/docs/react for configuration and current data-flow boundaries.
